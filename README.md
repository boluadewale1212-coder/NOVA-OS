## ✨ Features

- 📸 ViewOnce media capture to owner DM
- 🤖 command-based bot system
- 👤 owner control commands
- 💬 DM and group support
- ⚙️ environment-based config
- 🔐 Baileys WhatsApp integration

---

## 🔧 Install

```bash
npm install
cp .env.example .env
```

Edit `.env` and set your values.

## ▶️ Run

```bash
npm start
```

Scan the QR code with WhatsApp to authenticate.

## 📖 Commands

```text
.help
.ping
.info
.owner
```

Owner-only:

```text
.restart
```

## ⚠️ Notes

- Keep `.env` private
